Level2 is a no-code systematic-trading platform from Bytemine Technologies Ltd that lets active retail traders build, backtest and deploy fully automated strategies from a visual drag-and-drop canvas, with no code and no proprietary scripting language. Strategies can be rehearsed against historical data or paper-traded with virtual funds before being deployed live through a connected brokerage account. Level2 also sells the platform to brokers and prop firms as an embeddable surface: a customised iframe of the strategy builder, four standalone market widgets, and the Level2 Hub Broker API, which lets a broker register and manage its own customers' Level2 accounts, read their strategies, deployments, trades and backtests, and measure their execution latency and slippage.

**Areas:** Trading · Fintech · Financial Services · Automation · No-Code · Backtesting · Strategies · Brokerage · Market Data · Prediction Markets

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Level2: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
